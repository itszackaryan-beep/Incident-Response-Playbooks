
# Diagrams

## Overview

This directory contains the architecture and workflow diagrams used in the **Data Exfiltration Detection and Investigation** project.

The diagrams illustrate how confidential files are staged, monitored using Microsoft Sysmon, and investigated through Splunk Enterprise.

---

## Contents

### Lab_Architecture.png

Illustrates the lab environment including:

- Windows Server 2022
- Microsoft Sysmon
- Splunk Enterprise
- VMware Workstation

---

### Data_Exfiltration_Workflow.png

Shows the complete investigation workflow:

- Company Data Creation
- Data Collection
- Data Staging
- ZIP Archive Creation
- Sysmon Detection
- Splunk Investigation
- IOC Extraction
- MITRE ATT&CK Mapping
- Incident Response

---

## Purpose

These diagrams provide a visual representation of the simulated data exfiltration investigation and the overall SOC analysis workflow.

---

## Note

The diagrams represent a safe cybersecurity lab simulation. No confidential information was transferred outside the system during this project.
