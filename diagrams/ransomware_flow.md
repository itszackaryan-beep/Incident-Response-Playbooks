
# Diagrams

## Overview

This directory contains the architecture and workflow diagrams used in the **Ransomware Detection and Investigation** project.

These diagrams provide a visual representation of the lab environment, log collection process, and ransomware detection workflow using Microsoft Sysmon and Splunk Enterprise.

---

## Contents

### Lab_Architecture.png

Illustrates the cybersecurity lab environment, including:

- VMware Workstation
- Windows Server 2022
- Microsoft Sysmon
- Splunk Enterprise
- Universal Forwarder

---

### Ransomware_Detection_Workflow.png

Shows the complete ransomware investigation workflow:

- Ransomware Simulation
- Sysmon Event Generation
- Windows Event Logs
- Splunk Enterprise
- Detection
- Investigation
- Incident Response

## Purpose

These diagrams help explain the overall architecture and investigation workflow used throughout the ransomware detection project.
