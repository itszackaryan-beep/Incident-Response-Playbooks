
# Diagrams

## Overview

This directory contains the architecture and workflow diagrams used in the **Brute Force Detection and Investigation** project.

The diagrams illustrate the lab setup, authentication flow, Windows Security log generation, and Splunk investigation process.

---

## Contents

### Lab_Architecture.png

Illustrates the lab environment including:

- Kali Linux
- Windows Server 2022
- Microsoft Sysmon
- Windows Security Logs
- Splunk Enterprise

---

### Brute_Force_Attack_Flow.png

Shows the brute force investigation workflow:

- Failed Login Attempts
- Windows Security Event ID 4625
- Successful Login (Event ID 4624)
- Splunk Detection
- IOC Extraction
- MITRE ATT&CK Mapping
- Incident Response

---

## Purpose

These diagrams provide a visual understanding of the authentication monitoring and brute force investigation process.

---

## Note

All activities shown in these diagrams were performed in a safe laboratory environment for cybersecurity learning purposes.
