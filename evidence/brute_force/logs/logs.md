# Logs Folder

This folder contains sample log outputs collected during the brute force attack simulation.

The logs were generated in a controlled VMware lab environment using:

- Windows Server 2022
- Kali Linux
- Splunk Enterprise
- Windows Security Event Logs

## Log Files

| File | Description |
|------|-------------|
| EventID4625.txt | Failed Windows authentication events |
| EventID4624.txt | Successful Windows authentication events |
| IOC_Extraction.txt | IOC information extracted from Splunk |

These logs are provided for educational and defensive cybersecurity purposes only.
